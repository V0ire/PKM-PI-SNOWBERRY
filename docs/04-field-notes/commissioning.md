# Checklist Commissioning Snowberry

- [ ] Jalur 12V dan 24V tidak tertukar
- [ ] Semua GND common
- [ ] Output LM2596 sudah 5.00V
- [ ] Fuse 12V terpasang
- [ ] Fuse 24V terpasang
- [ ] Pompa OFF saat boot
- [ ] Mist disc OFF saat boot
- [ ] Kipas OFF saat boot
- [ ] Growlight OFF saat boot
- [ ] ESP32 menyala stabil
- [ ] I2C scanner menemukan SHT30 dan BH1750
- [ ] Soil sensor terbaca
- [ ] Data masuk Firebase
- [ ] Dashboard tampil
